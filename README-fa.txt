Study OS v84 — راهنمای به‌روزرسانی

این بسته شامل همان برنامه و همگام‌سازی نسخهٔ ۸۳ با بازنگری چیدمان سه دستگاهی است.

برای مخزن GitHub Pages موجود، فایل‌های داخل ZIP را در ریشهٔ مخزن بارگذاری و فایل‌های هم‌نام را جایگزین کنید. سپس Commit changes بزنید.

فایل پشتیبان JSON را هرگز به مخزن عمومی اضافه نکنید.

نکات نسخهٔ ۸۴:
- چیدمان دسکتاپ از CSS پایه استفاده می‌کند و هدف اصلاحیه نیست.
- چیدمان گوشی از قواعد موبایل موجود استفاده می‌کند و در این نسخه دست‌کاری نشده است.
- چیدمان تبلت به دو حالت عمودی و افقی تفکیک شده است.
- بسته‌شدن پنل کناری آزمون‌زنی در هر دو جهت باید ستون پنل را کاملاً حذف کند.
- منطق ذخیره‌سازی، کلیدهای محلی، همگام‌سازی و کنترل RGB تغییر داده نشده‌اند؛ فقط رنگ‌بندی نوار ناوبری منتقل‌شده به Portal از پوستهٔ اصلی پیروی می‌کند.


نسخه ۸۵: انتخاب دستی چیدمان دستگاه (تشخیص خودکار / سیستم / تبلت / گوشی) اضافه شد. انتخاب در حافظهٔ محلی همین مرورگر ذخیره می‌شود و بین دستگاه‌ها همگام نمی‌شود؛ بنابراین هر دستگاه می‌تواند چیدمان مستقل خودش را داشته باشد. برای انتشار، تمام فایل‌های بسته را در ریشهٔ مخزن GitHub جایگزین کنید.
