Study OS v79 — فایل‌های انتشار GitHub Pages

این فایل‌ها را پس از ساخت یک مخزن عمومی، مستقیماً در ریشهٔ مخزن قرار بده.
فایل index.html باید در ریشه باشد.

فایل‌های لازم:
- index.html
- cloud-sync.js
- sw.js
- manifest.webmanifest
- icon-192.png
- icon-512.png
- .nojekyll

مهم:
- فایل پشتیبان JSON را هرگز در مخزن عمومی بارگذاری نکن.
- کلید service_role یا secret را هرگز در فایل‌های سایت قرار نده.
- کلید publishable موجود در کد، کلید عمومی مرورگر است؛ امنیت داده‌ها باید با RLS در Supabase حفظ شود.
- مخزن عمومی است و کد برنامه برای همه قابل مشاهده خواهد بود.
- پس از انتشار، نشانی GitHub Pages را در تنظیمات URL پروژهٔ Supabase تنظیم می‌کنیم.
